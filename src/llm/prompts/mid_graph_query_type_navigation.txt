## Rules

1. Set `sufficient=true` only if this agent's current memories contain a specific answer. Then return empty `missing` and `selected_edges`.
2. Otherwise state the missing information precisely and select every edge that is strongly likely to recover it; multiple edges are allowed.
3. Use direction semantically. For example, reverse `causes` can recover a cause from a known result, while forward `causes` can recover an outcome; reverse `precedes` finds an earlier stage and forward finds a later stage.
4. For `when` questions, prefer temporal edges only when their direction and description lead toward the requested earlier/later event or time clue.
5. For `how` or `why` questions, prefer causal, enabling, explanatory, or ordered-step edges only when their descriptions expose the requested mechanism or reason.
6. For `what`, `who`, `where`, and other fact questions, let the concrete description override generic type preference.
7. Reject edges that merely share a theme, repeat a habit, or move away from the missing information. Relation-label match alone is never enough.
8. Give one concise reason for every selected edge. Return exact edge IDs and no invented facts.
